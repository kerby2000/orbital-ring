# Legacy OR-1 evidence

These files are retained to preserve the reviewed OR-1 evidence associated with
the initial repository commit. They use the original manifest schema and are
not regenerated or amended by OR-1.1.

New bulk outputs belong in ignored `artifacts/generated/` or `ci-evidence/` and
are archived by CI. Small canonical OR-1.1 tables are tracked under
`evidence/or-1.1/`. See `GENERATED_ARTIFACTS.md`.
